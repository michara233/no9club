## 找内容

### 导航栏

顶部导航栏依次是首页、归档、分类、标签、指南。手机上是左上角的菜单按钮。

### 站内搜索

点导航栏的**搜索图标**，弹出输入框，**边输边出结果**（搜索索引在页面加载时就预取好了，不用等）。按 `Esc` 或点空白处关闭。

搜索覆盖文章标题和正文。两点说明：

- 加密文章的正文是密文，**搜不到里面的内容**，只能搜到标题。
- 搜索索引随站点构建一起更新，刚发布的文章可能要等 Cloudflare 重新构建完成才搜得到。

### 归档 / 分类 / 标签

按时间翻旧文用**归档**，找某一类主题用**分类**，只记得一个词（比如"序列帧"）就直接用**标签**或搜索。

## 调阅读体验

右下角有个**齿轮按钮**，鼠标移上去（手机上点一下）会展开一排小工具：

| 工具 | 作用 |
| --- | --- |
| 月亮 / 太阳 | 切换深色、浅色模式。默认跟随系统设置，手动切过之后会记住你的选择 |
| 调色板 | 切换配色，见下一节 |
| 放大镜 ＋ / － | 调正文字号，字小了就调大一点 |
| 上箭头（带百分比） | 回到页面顶部，顺便显示当前阅读进度 |
| 下箭头 | 直接跳到页面底部，长文想找结尾的下载链接时好用 |
| RSS 图标 | 本站的订阅地址 |

### 两套配色

本站准备了**两套配色**，随你挑：

| 配色 | 观感 |
| --- | --- |
| **NO9 品牌色**（默认） | 近黑底配霓虹红，和俱乐部 logo 是一套 |
| **经典配色** | 白底或深灰底配酒红，素净一些 |

点齿轮里的**调色板图标**就能切换，选择会记在当前浏览器里，下次打开还是它。

配色和深浅色是**两件独立的事**，可以任意组合，比如"经典配色 + 深色模式"、"品牌色 + 浅色模式"都行。

只想临时看一眼另一套、又不想改设置：在网址后面加上参数即可，关掉页面就恢复原样。

- `?palette=classic` —— 临时用经典配色
- `?palette=brand` —— 临时用品牌色

## 加密文章怎么解锁

有些文章（比如内部教程）设了密码，打开会看到一个密码框：

1. 输入密码，按**回车**。
2. 密码正确，正文当场解密显示；密码错误会弹窗提示，重新输入即可。
3. 解锁过的文章，**同一个浏览器下次打开就是展开状态**，不用再输。

正文末尾会多出一个**「重新上锁」**按钮，点了会清掉浏览器里记住的密码并刷新页面，适合在公用电脑上看完随手锁上。

三件需要提前知道的事：

- 加密**只保护正文**。标题、日期、摘要仍然是公开的，别拿它放真正敏感的东西。
- 密码由管理员设置，**忘了只能找管理员要**，本站没有找回功能。
- 加密文章的内容不进站内搜索索引，搜不到里面写了什么。

## 图片、代码和附件

**图片可以点开放大。**文章里的图点一下就进看图模式，底部有左右切换按钮，也可以直接用方向键翻页，`Esc` 退出。如果图片是相机原图，看图时还能翻到拍摄参数（EXIF）。

**代码块一键复制。**鼠标移到代码块上，右上角会出现复制按钮。

**大文件不在站内。**安装包、压缩包这类几十上百 MB 的东西放在网盘，文章里会给出链接和提取码。国内下载建议直接用这些链接，比走 GitHub 快很多。

## 订阅更新

本站提供 RSS / Atom 订阅：

```
https://no9club.pages.dev/atom.xml
```

把地址复制进任意阅读器即可（Feedly、Inoreader、蚁阅、NetNewsWire 等），有新文章会自动出现，不用天天来刷首页。也可以点右下角工具盘里的 RSS 图标打开订阅文件。

## 装到手机上，当 App 用

本站支持"添加到主屏幕"，装完是一个独立图标，打开后没有浏览器地址栏，看着就是个 App：

| 设备 | 怎么装 |
| --- | --- |
| Android（Chrome / Edge） | 右上角菜单 → 安装应用 / 添加到主屏幕 |
| iPhone、iPad（Safari） | 分享按钮 → 添加到主屏幕 |
| 电脑（Chrome / Edge） | 地址栏右侧会出现安装小图标，点它 |

装好之后：图标是本站自己的，状态栏配色跟着当前配色走；**看过的页面断网也能打开**；配色切换、深浅色、搜索这些功能照常可用。

## 常见问题

**换了配色、或者刚发了新文章，页面还是旧的？**

按 `Ctrl+F5` 强制刷新一次（Mac 是 `Cmd+Shift+R`）。本站带离线缓存，正常情况下刷新一次就是最新的。

**手机上的配色变了，或者深浅色不跟系统了？**

这些选择记在**当前这个浏览器**里。换个浏览器、清了缓存、或者用无痕模式打开，都会回到默认。想强制指定，用上面说的网址参数。

**文章能转载吗？**

每篇文章底部都标了版权声明，按上面的许可来就行，一般是"署名 - 非商业性使用 - 相同方式共享"。
